# Forge Agent

Corre en la máquina del taller. Escucha los prompts del módulo Forge de
Mono Atelier OS, diseña con el motor mono-forge, construye en Blender y publica
el resultado (3D, AR y entregables) de vuelta en la plataforma.

    python -m forge_agent.worker

Guía completa: `../mono-forge/docs/AGENTE_PROMPTS.md`
